# Remote Worker integration plan

Implement and test a loopback-only authenticated HTTP client with durable start intent, immutable spec verification, ordered events and no automatic start retry. Adapt the Orchestrator execution interface to this protocol. Each round uses a new immutable Worker registration; an approved completed predecessor is mounted read-only inside the next isolated sandbox, its commit is bound in the spec, and the runner creates a local checkpoint without pushing. Stop is terminal, Interrupt cancels the task, and Pause is a round boundary. Synthetic integration uses the actual HTTP handler, policy, store and controller with temporary privileged execution plumbing. Finish public review, fresh regression, then conditionally push the feature branch and observe CI.
